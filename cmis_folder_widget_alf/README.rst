This module completes the CMIS folder widget (``cmis_folder_widget``)
with the functionalities of Alfresco (``cmis_alf`` module of
`Alfodoo <https://github.com/acsone/alfodoo>`__). It is installed
automatically with both modules.

- **Preview of the office documents**: the documents of Microsoft
  Office, LibreOffice / OpenDocument, RTF and CSV are previewed in the
  Odoo file viewer from their PDF rendition, generated by Alfresco on
  demand. Like the other contents, the rendition is served by Odoo, once
  the access checked; the download is still the original document.
- **Links to Alfresco Share** (optional): open a document or a folder in
  Alfresco Share, for the users having an Alfresco account.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

On the CMIS backend (*Settings > Technical > CMIS > Backends*), in the
*Folder widget* section:

- **Links to Alfresco Share**: display the *Open in Alfresco Share*
  action, using the *Alfresco Share Url* of the backend;
- **Preview generation timeout**: maximum time to wait for Alfresco to
  generate the PDF preview of a document (15 seconds by default).
