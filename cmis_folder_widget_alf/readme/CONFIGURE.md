On the CMIS backend (*Settings > Technical > CMIS > Backends*), in the
*Folder widget* section:

- **Links to Alfresco Share**: display the *Open in Alfresco Share* action,
  using the *Alfresco Share Url* of the backend;
- **Preview generation timeout**: maximum time to wait for Alfresco to
  generate the PDF preview of a document (15 seconds by default).
