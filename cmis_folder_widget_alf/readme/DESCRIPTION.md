This module completes the CMIS folder widget (`cmis_folder_widget`) with
the functionalities of Alfresco (`cmis_alf` module of
[Alfodoo](https://github.com/acsone/alfodoo)). It is installed automatically
with both modules.

- **Preview of the office documents**: the documents of Microsoft Office,
  LibreOffice / OpenDocument, RTF and CSV are previewed in the Odoo file
  viewer from their PDF rendition, generated by Alfresco on demand. Like the
  other contents, the rendition is served by Odoo, once the access checked;
  the download is still the original document.
- **Links to Alfresco Share** (optional): open a document or a folder in
  Alfresco Share, for the users having an Alfresco account.
